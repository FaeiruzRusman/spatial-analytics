SUO Spatial Analytics Engine v3.0

This version is structured as an enterprise analytics workspace:

  • Data Manager — registers and imports analytical layers.
  • Analysis Manager — selects and executes analysis models.
  • Workflow Manager — validates, processes and reports job progress.
  • Result Manager — renders spatial outputs, KPIs, statistics and charts.
  • History Manager — stores recent analysis jobs locally.
  • Export Manager — exports GeoJSON and analysis reports.
  • GeoPortal Handoff — prepared for future connection to the SUO 3D GeoPortal.

Phase 1 currently uses synthetic population and facility data for engine validation. Replace these with verified DOSM/SUO datasets before production.
